# Living Daya

An informational website for Sikhs in Canada on Daya (compassion), Sarbat da Bhala, and plant-based living.

- `content/website-content.md`: website text (v3, rewritten from scratch), with footnoted sources
- `docs/verification-checklist.md`: what's confirmed, what's left to verify, and the editorial rules
- `docs/tech-setup.md`: static site generator and GitHub Pages plan
